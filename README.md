# 🚀 Project 365

### 365 Days. 365 Builds. One Engineer in the Making.

**Project 365** is my long-term challenge to build something meaningful every day for 365 days while developing the skills required to become a **production-ready AI engineer**.

This repository is the public record of that journey.

* Read logs from a file
* Count `INFO`, `WARNING`, and `ERROR`
* Extract errors
* Extract warnings
* Find the most common error
* Generate a terminal report

**Technologies:** Python

# 📈 Development Principles

Throughout Project 365, I will follow a few rules:

### 1. Build > Watch

Learning should result in something tangible.

### 2. Understand > Copy

Code copied from tutorials doesn't count as mastery.

### 3. Debug > Give Up

Errors are part of the process.

### 4. Progressively Harder

Projects should become more challenging over time.

### 5. Refactor

Early solutions don't have to be perfect. They should improve with experience.

### 6. Document

Every meaningful project should explain what was built, why it was built, and what was learned.
