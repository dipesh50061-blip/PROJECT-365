# 🚀 TaskFlow

> A simple, persistent task management system built with Python.

TaskFlow is a **Python-based task management application** designed to help users create, manage, track, and organize their daily tasks.

This project was built as part of **Project 365** — my journey of building something meaningful with code every day and continuously improving my software engineering skills.

---

## ✨ Features

* ➕ Add new tasks
* 📋 View all tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 💾 Persistent task storage using JSON
* 🔄 Load tasks automatically when the application starts
* 🕒 Track task information
* 🧩 Modular Python architecture
* 🏗️ Designed to evolve into an OOP-based system

---

## 🛠️ Tech Stack

* **Python 3**
* **JSON** — persistent data storage
* **Functions & Modular Programming**
* **Git & GitHub**

## 📂 Project Structure

```text
TaskFlow/
│
├── main.py
├── task_manager.py
├── tasks.json
└── README.md
```

### `main.py`

The main entry point of the application.

It handles:

* User interaction
* Menu system
* Taking input
* Calling task-management functions

### `task_manager.py`

Contains the core task-management logic.

It is responsible for operations such as:

* Adding tasks
* Viewing tasks
* Updating task status
* Deleting tasks

### `tasks.json`

Stores task data so that tasks remain available even after the program is closed.
