## 🖥️ How It Works

The application provides a simple interface where users can enter their expenses and manage their spending.

A typical workflow looks like:

```text
Start
  ↓
Add Expense
  ↓
Enter Amount
  ↓
Select Category
  ↓
Enter Description
  ↓
Store Expense
  ↓
View / Calculate Expenses
  ↓
Manage Spending
```
