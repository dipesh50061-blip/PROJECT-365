# Day 01 — LogForge

A Python-based log analysis tool built as part of Project 365.

## Features

- Reads application logs from a file
- Counts INFO, WARNING, and ERROR logs
- Finds all errors
- Finds all warnings
- Finds the most common error
- Generates a summary report

## Technologies

- Python

- Exception handling
- Lists
- Dictionaries
